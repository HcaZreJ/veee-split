# Veee 分流助手

给 Veee+ 加上自动分流：挂着 Veee 的同时国内网站照样快；在 Veee 里随便切节点，分流自动跟随。装完之后不需要碰终端。

## 它解决什么

- Veee 全局模式下国内网站又慢又打不开 → 装完后国内网站自动直连
- 切到国内节点是为了让 App 看到国内 IP → 装完后自动识别节点地区，国内网站自动改走节点
- 每次切节点，代理设置被 Veee 抢走 → 后台守护自动抢回来，全程无感

## 安装（一次性，约 1 分钟）

1. 打开 Veee，登录，连接任意一个节点
2. 双击 `install.command`
   - 如果系统提示「无法打开」：右键点它 → 打开 → 打开
3. 看到绿色的「安装完成」即可关掉窗口

## 日常使用

在 Veee 里正常切节点，其它什么都不用管：

| 你在 Veee 里做什么 | 自动发生什么 |
|---|---|
| 连上美国 / 新加坡 / 台湾节点 | 国内网站直连（快），其余走节点 |
| 连上国内节点 | 国内网站走节点（拿国内 IP），其余直连 |
| 关掉 Veee | 全部恢复直连 |

## 想加「直连的国内网站」

把这个文件夹给你的 Claude，说：「帮我把 xxx.com 加到国内清单」。
或者自己打开终端输入：`veee-split add-direct 网站域名`

## 出问题了

打开「终端」（启动台里搜 terminal），输入 `veee-split` 回车，把输出发给你的 Claude 或发给我。

## 卸载

双击 `uninstall.command`，然后在 Veee 里重连一次节点。
